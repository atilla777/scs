# SuperCollider — технический Agent Skill

- **Тип:** product requirements / OKF bundle
- **Статус:** требования согласованы, реализация не начата
- **Дата:** 2026-10-19
- **Область:** переносимый Agent Skill для работы с локальным SuperCollider
- **Основная платформа:** Linux (Omarchy / Arch Linux)

## Замысел

Предоставить AI-агенту (OpenCode, Codex и любому совместимому с Agent Skills харнесу) **техническую компетенцию** по SuperCollider: находить справку установленной версии, писать и отлаживать `sclang`-программы, исполнять их, рендерить аудио через `scsynth` в NRT, проверять результат. Графический интерфейс и физическое аудиоустройство не должны быть обязательными для офлайн-операций.

Скилл намеренно **не отвечает за музыкальное творчество**: сочинение, аранжировку, подбор художественных тембров и оценку красоты звучания. Это предмет будущего более высокого уровня `music-composition`, который сможет использовать технический скилл. Интеграция с Remotion также остаётся вне его границ.

## Правила использования в RIS

- Бандл представляет **принятые продуктовые требования**; он является исходным описанием ожидаемого поведения, а не техническим планом реализации.
- Эпики, фичи и задачи roadmap отслеживаются в **трекере**, а не в этом бандле.
- При декомпозиции связывать задачи и проверки с идентификаторами требований (`FR-*`, `NFR-*`) и критериев (`AC-*`).
- Внутренний код CLI, конкретный язык реализации, формат служебного протокола и библиотеки аудиоанализа определяются на этапе проектирования фич, если здесь не задано ограничение.
- Изменение согласованных границ и поведения требует пересмотра соответствующих требований.
